How to use it

Building a machine

  • Pick the state tool and click the canvas to place a state. The first one becomes the start state.
  • Pick the transition tool and drag from one state to another.
  • Double-click a state to rename it or make it accepting; right-click for the same menu.
  • Drag with the select tool to move states. Hold space and drag to pan; scroll to zoom toward the cursor.

Transition syntax

  • DFA / NFA — a comma-separated set of symbols, e.g. 2, 3, 4. A DFA stays deterministic as long as the sets leaving a state do not overlap. Use ε for an epsilon move (NFA only).
  • PDA — read, pop and push. A pop of ε pops nothing; the leftmost pushed character ends up on top. Z starts on the stack.
  • Turing machine — read, write and a direction. □ is the blank symbol.

Running it

  • Run plays the whole input; Step advances one configuration at a time.
  • The result panel shows the input with the consumed prefix struck through and the symbol under the head highlighted.
  • Batch test takes one string per line and reports each verdict. Write ε for the empty string. Loading an example fills it with strings that are known to be in, and known to be out of, the language.

Keyboard

  • V select · S state · T transition · D delete · F fit
  • Ctrl+Z undo · Ctrl+Y redo · Del remove selection
  • Enter in the input box runs · → steps · Esc closes dialogs
